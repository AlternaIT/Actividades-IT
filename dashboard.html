⚙️ Configuración de base de datos requerida
Para que esta sección funcione completamente, la tabla profiles debe tener los campos: email TEXT, area TEXT, is_active BOOLEAN DEFAULT true, last_seen TIMESTAMPTZ. El reset de contraseña usa supabase.auth.resetPasswordForEmail() — el usuario recibirá un email. La creación de usuarios usa supabase.auth.signUp() — requiere que el registro esté habilitado en Supabase Auth.

👤 Descripción de roles

Admin

Acceso total al sistema. Puede crear/desactivar usuarios, cambiar roles y modificar configuración.

Supervisor

Puede ver y gestionar todas las actividades y ver el directorio de usuarios. No puede crear ni desactivar usuarios.

Técnico

Ve y edita únicamente sus propias actividades. Sin acceso a usuarios ni configuración.

Consulta

Solo lectura. Puede ver actividades y dashboard pero no crear ni editar nada.
